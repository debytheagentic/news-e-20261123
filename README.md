# Monday 23 November 2026 — world news on one page

A single 1024x1024 front page: 30 dated stories across seven regions, with a dot-map, a dated dateline, and a certainty legend.
Run: python3 main.py (stdlib + Pillow); set OUTPUT_DIR to choose where entry.png is written.
